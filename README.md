# Investment Analyzer V1

אפליקציית מחקר מניות בעברית: מקלידים טיקר, לוחצים **נתח מניה**, ומקבלים דוח פיננסי, גרפים אינטראקטיביים, ניתוח טכני, הסברים וניקוד שקוף. כל ההסברים נוצרים בכללים בקוד, ללא AI או מפתח API.

## 1. הקבצים המוכנים

- `app.py` — האפליקציה המלאה.
- `requirements.txt` — חמש הספריות בגרסאות שנבדקו יחד.
- `README.md` — מדריך זה, כולל רשימת בדיקות.
- `.streamlit/config.toml` — ערכת צבעים כהה והגדרות הפעלה. מומלץ, אך האפליקציה פועלת גם בלעדיו.

יש לחלץ את קובץ ה־ZIP לפני ההעלאה. אין להעלות את ה־ZIP עצמו בתור קוד האפליקציה.

## 2. יצירת מאגר ב־GitHub — דרך הדפדפן בלבד

1. פתח חשבון חינמי ב־[GitHub](https://github.com) והתחבר.
2. לחץ **+ → New repository**.
3. שם המאגר: `investment-analyzer`.
4. בחר **Public**, כדי להשתמש במסלול הקהילתי הפשוט. הקוד יהיה גלוי לציבור; אין בפרויקט סיסמאות או מידע אישי.
5. לחץ **Create repository**.
6. במאגר החדש לחץ **uploading an existing file**. אם כבר יש בו קבצים: **Add file → Upload files**.
7. גרור את `app.py`, את `requirements.txt` ואת `README.md` מתוך התיקייה שחילצת. הם צריכים להופיע בשורש המאגר, בלי תיקיית עטיפה נוספת.
8. לחץ **Commit changes**.
9. כדי להוסיף את ערכת העיצוב: **Add file → Create new file**. בשדה השם כתוב בדיוק `.streamlit/config.toml`, הדבק את תוכן קובץ ההגדרות ולחץ **Commit changes**. הדרך הזו נוחה גם אם המחשב מסתיר את התיקייה המתחילה בנקודה.

בסוף יש לראות את `app.py` ואת `requirements.txt` מיד כשפותחים את המאגר; ובתיקיית `.streamlit` את `config.toml`.

## 3. הפעלה ב־Streamlit Community Cloud

1. פתח את [Streamlit Community Cloud](https://share.streamlit.io) והתחבר באמצעות GitHub. השלם את חיבור החשבונות אם תתבקש.
2. בחר **Create app**, ואם מופיעה השאלה האם כבר יש אפליקציה, בחר **Yup, I have an app**.
3. בחר את המאגר `investment-analyzer`.
4. בחר את הענף `main` (או את שם הענף שבו העלית את הקבצים).
5. בשדה **Main file path** כתוב `app.py`.
6. ב־**Advanced settings** בחר **Python 3.12**. אין צורך להוסיף Secrets או מפתח API.
7. לחץ **Deploy** והמתן לסיום התקנת הספריות והפעלת האפליקציה.
8. הכתובת שתקבל מסתיימת ב־`streamlit.app`. פתח אותה מכל מחשב, הקלד `TSLA` ולחץ **נתח מניה**.

אין צורך להתקין Python אצלך או להשאיר את המחשב דולק. זמן ההקמה הידני הוא בדרך כלל כ־10–25 דקות אם החשבונות מוכנים; זמני הרשמה, התקנה, תור ושירותי צד שלישי אינם בשליטת הקוד. לא נוצרו עבורך בשלב זה מאגר בחשבון או כתובת אתר פעילה.

המסלול Community Cloud מוצג כחינמי. בחר בו; אין צורך ב־Snowflake בתשלום. [האתר הרשמי](https://streamlit.io/) ו[הוראות ההפעלה הרשמיות](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy).

## 4. מה כלול

- מחיר אחרון, שינוי יומי, מטבע, שווי שוק, ענף, תעשייה וטווח 52 שבועות.
- תמחור: P/E, Forward P/E, PEG, P/S, P/B, EV ו־EV/EBITDA.
- הכנסות וצמיחה, EPS, תחזית EPS וגרף הכנסות שנתי לפי השנים שהמקור מספק.
- שיעורי רווחיות, ROE ו־ROA.
- תזרים שנתי: פעילות שוטפת, FCF ו־CAPEX, עם תאריך תקופה.
- מאזן: מזומן, חוב, מזומן נטו, חוב/הון ויחס שוטף.
- SMA50, SMA150, SMA200 ו־RSI14 לפי Wilder, עם הסברים בעברית.
- גרף Plotly לטווחי חצי שנה, שנה, שלוש וחמש שנים.
- תשואות חודש, שלושה ושישה חודשים, YTD, שנה, שלוש וחמש שנים.
- חמישה ציוני מחקר, הסבר למקור כל ציון, כיסוי נתונים ופירוט כללי החישוב.
- הסבר פשוט, חוזקות ונקודות לתשומת לב, מבוססי נתונים בלבד.
- Compare Stocks: השוואה של עד חמש מניות.
- Watchlist של עד 20 טיקרים במושב הדפדפן הנוכחי, ללא מסד נתונים או חשבון משתמש.
- מטמון של 15 דקות וכפתור לרענון נתוני הנכסים שבמסך.

## 5. איך לקרוא נכון את הדוח

**זמני נתונים:** זמן השליפה מוצג ב־UTC, בנפרד מזמן הציטוט אם התקבל ומהתאריך האחרון בהיסטוריית המחירים. Yahoo עשוי לספק נתונים מושהים. נתון מדוח שנתי אינו נתון בזמן אמת.

**תקופות:** דוח התזרים והמאזן משתמשים בשנת הדיווח האחרונה הזמינה. נתוני הרווחיות וההכנסות בסיכום Yahoo הם בדרך כלל ל־12 חודשים; צמיחת הכנסות ורווחים בדרך כלל מתייחסת לרבעון מול הרבעון המקביל. צמיחת EPS מחושבת בין שתי שנות דיווח עוקבות, ורק מבסיס חיובי. לא מערבבים שנות מאזן כדי לחשב מזומן נטו. בהשוואה נעשה שימוש ב־FCF מסיכום Yahoo, שעשוי להיות שונה מהתזרים השנתי בדוח הראשי.

**מחירים ותשואות:** הניתוח הטכני משתמש ב־Close מותאם לפיצולים, ללא התאמת דיבידנדים. התשואות משתמשות ב־Adj Close, המותאם גם לדיבידנדים, והן מצטברות ולא תשואות שנתיות ממוצעות. יום המסחר האחרון עשוי עדיין להיות בעיצומו. YTD נמדד מסגירת השנה הקודמת. חברה צעירה לא מקבלת תשואת חמש שנים אם אין לה היסטוריה מספקת.

**מטבעות:** מטבע המסחר ומטבע הדוחות מופיעים בנפרד. אין המרת מטבע אוטומטית. K = אלפים, M = מיליונים, B = מיליארדים, T = טריליונים. חוב/הון מוצג בפעמים: 1.5 = 150%.

**ניקוד:** כל קטגוריה שווה 20 נקודות. הנתונים הזמינים בתוך קטגוריה מקבלים משקל שווה. ציון קטגוריה דורש כיסוי של 60%; ציון כולל דורש לפחות 75% בכל אחת מחמש הקטגוריות. נתון חסר אינו אפס. כל הספים והתרומות גלויים באפליקציה, לרבות התאמה גסה לתמחור לפי ענף וצמיחת הכנסות. אין כאן דירוג ביחס לחברות מתחרות, בדיקה היסטורית או מודל שווי הוגן. אין להשתמש בציון כתחזית תשואה. לחברות פיננסיות ונדל״ן אין ציון כללי משום שהמודל אינו מתאים להן; גם ETF ונכס שלא זוהה כמניה אינם מקבלים ציון עסקי.

**מידע חסר:** מוצג ״נתון לא זמין״. FCF שלילי מסומן, אך אין הסקת סיבה ללא נתונים. אין טענות על שחיקת מרווחים או האטת צמיחה שלא נמדדו לאורך זמן.

## 6. Test Checklist — לאחר ההפעלה

הבדיקות כאן הן בדיקות קבלה שאתה יכול לבצע בכתובת שלך. אין צורך לתכנת.

- [ ] `TSLA`: לחיצה על נתח מציגה שם חברה, מחיר, זמן נתונים וארבע לשוניות דוח.
- [ ] `AAPL`: בדוק הופעת תמחור, רווחיות, הכנסות ותזרים, או הודעה מפורשת אם שדה חסר.
- [ ] `NVDA`: בדוק שגרף המחיר ו־SMA מוצגים, ושאפשר לעבור בין כל ארבעת הטווחים.
- [ ] `GOOGL`: בדוק תשואות ושאין ערבוב בין מחיר נוכחי לתאריך החישוב הטכני.
- [ ] `AMZN`: בדוק את ״במילים פשוטות״ ואת פירוט המדדים בלשונית הניקוד.
- [ ] השווה `TSLA NVDA GOOGL`: שלוש שורות, מטבעות, מכפילים, צמיחה, FCF, חוב/הון ו־ROE.
- [ ] הוסף `AAPL` לרשימת מעקב, נתח מהרשימה והסר אותה.
- [ ] `SPY`: האפליקציה מזהה ETF, מאפשרת גרף ותשואות ואינה נותנת ניקוד עסקי של חברה.
- [ ] `ZZZZINVALID123`: הודעת אי־זמינות או כשל מקור, ללא מסך קריסה.
- [ ] קלט ריק או `<script>`: הודעת טיקר לא תקין.
- [ ] חברה חדשה: תשואות שאין להן מספיק היסטוריה מופיעות כלא זמינות.
- [ ] חברה הפסדית: מכפיל רווח לא תקף אינו מוצג כמכפיל זול.
- [ ] לחץ ״רענן נתונים מהמקור״: הדוח נטען מחדש; השוואה קודמת מתנקה ויש ללחוץ שוב על השווה.
- [ ] הרחב ״למה התקבל כל ציון״ וודא שאפשר לראות ערכים, תרומות וכיסוי נתונים.

### בדיקות שבוצעו בהכנת הפרויקט

בוצעה התקנת חמש התלויות בגרסאות שב־requirements, בדיקת תחביר והרצת Streamlit AppTest עם נתוני בדיקה מבוקרים. נבדקו נוסחת Wilder מול ערך ייחוס, RSI במגמה עולה/יורדת/שטוחה, SMA200, YTD, היסטוריה קצרה, מזומן נטו באותו תאריך, צמיחת EPS, נתונים חסרים וניקוד. מסכי TSLA/AAPL/NVDA/GOOGL/AMZN נבדקו עם נתונים מדומים; זו בדיקת התנהגות ולא אימות הציטוטים של אותן חברות. בסך הכול עברו 32 בדיקות, כולל הוספה לרשימת מעקב, ניתוח ממנה ורענון מטמון. גם בדיקת התאימות בין הספריות עברה ללא התנגשויות.

**שליפה חיה — מגבלה שנצפתה:** בניסיון עבור TSLA, AAPL, NVDA, GOOGL ו־AMZN לא התקבלו נתוני שוק בסביבת הבדיקה. בדיקת אבחון ישירה החזירה `YFRateLimitError: Too Many Requests`. לכן אין טענה שהשליפה החיה אומתה או שהאתר כבר פורסם. צריך לבצע את רשימת הקבלה גם לאחר הפריסה לחשבון שלך. הגבלת Yahoo עלולה להופיע גם ב־Community Cloud.

## 7. פתרון תקלות קצר

- **ModuleNotFoundError:** ודא ש־`requirements.txt` נמצא ליד `app.py`, ובחר Python 3.12.
- **המאגר אינו מופיע:** אשר ל־Streamlit גישה לחשבון GitHub, או הקלד את שם המאגר ידנית.
- **Main file לא נמצא:** קובץ `app.py` כנראה נמצא בתוך תיקיית עטיפה. העבר לשורש או תקן את הנתיב בעת ההפעלה.
- **אין נתונים / Too Many Requests / 429:** Yahoo עשוי לחסום זמנית בקשות משרתים משותפים. המתן 15 דקות ונסה שוב; אל תלחץ ברצף על רענון. אין API בתשלום כגיבוי, ולכן אין הבטחה לזמינות רציפה.
- **כל המניות ריקות:** בדוק קודם חיבור וזמינות Yahoo; אין להסיק שכל הטיקרים שגויים.
- **טעינה ראשונה איטית:** האפליקציה מורידה מספר דוחות והיסטוריה; זמן הטעינה תלוי במקור. הנתונים נשמרים במטמון לאחר מכן.
- **רשימת מעקב נעלמה:** היא זמנית בכוונה; ניתוק או רענון דפדפן עשויים לסיים את המושב.
- **האפליקציה נרדמה:** פתח אותה והפעל מחדש לפי הודעת Community Cloud.
- **שינוי קוד:** העלה את הקובץ המעודכן לאותו מאגר ובצע Commit; Streamlit קורא את העדכון מהמאגר.

## 8. למי שרוצה להריץ מקומית — לא נדרש לפריסה בענן

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

תיעוד המקור: [yfinance Ticker](https://ranaroussi.github.io/yfinance/reference/api/yfinance.Ticker.html). הנתונים תלויים בזמינות ובתנאי Yahoo; הספרייה אינה מבטיחה שירות רציף. האפליקציה מיועדת למחקר אישי וללמידה.

המערכת מיועדת למחקר ולמידה בלבד ואינה מהווה ייעוץ השקעות, המלצה לביצוע פעולה או תחליף לבדיקת מקורות פיננסיים רשמיים.
